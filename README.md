## 🏗️ Flagship Systems

### 🏨 SinoraIQ — Multimodal Document Intelligence & Supply Chain Platform
**The problem:** hospitality procurement runs on supplier documents in endless layouts, and every price change ripples through recipes and menus.
**What I built:**
- **Cost-optimised extraction engine** (Gemini): fast primary parsing, with reasoning-based escalation only for complex documents, delivering **>99% line-item accuracy at ~$0.012/document**
- **Self-healing configuration compiler:** an agent that studies unseen supplier layouts, generates validated extraction schemas and refines them from parsing and validation feedback
- **Layout-aware PDF segmentation** to split multiple invoices bundled in one file
- **Supplier email intelligence:** classifies replies, extracts counter-offers, validates pricing against contractual tolerances
- **Real-time recipe-cost propagation** through multi-level BOMs, sub-recipes, packaging and POS menu items
- **Event-driven reconciliation** of invoices against POs and goods-received records, with automated financial posting for zero-variance matches
- **Integrations:** Gmail, Microsoft 365, Google Drive, Epicor ERP, Xero, Shift8 POS, Deputy, plus tenant-aware LLM telemetry

`Python` `FastAPI` `Gemini` `PostgreSQL` `Next.js` `Keycloak` `Docker`

### 💬 SocialMind AI — Multi-Tenant Customer Messaging Automation *(in active development)*
**The problem:** businesses drown in repetitive WhatsApp, Messenger and Instagram inquiries, and generic bots make things up.
**What I'm building:**
- **Grounded RAG:** semantic retrieval + evidence coverage + intent classification + grounding validation, so unsupported answers don't get sent
- **Human-in-the-loop:** escalation tickets, owner notifications, live agent takeover over bidirectional WebSockets
- **One-instruction onboarding:** extracts business info, products, hours and FAQs to set up the knowledge base
- **Growth tooling:** tracked WhatsApp links, QR codes, attribution analytics, and outbound campaigns with Meta template sync and consent/opt-out enforcement
- **Multilingual:** English, Sinhala, Tamil, Singlish and Tanglish
- **Multi-tenant by design:** PostgreSQL tenant isolation, Pinecone namespaces, async processing with FastAPI, Celery and Redis

`Python` `FastAPI` `Gemini` `Pinecone` `PostgreSQL` `Celery` `Redis` `WebSockets` `Meta APIs`

### 🤖 AccDoo Platform Advisor — AI-Powered ERP Sales Assistant
**The problem:** prospects need accurate answers across a broad ERP (Finance, Inventory, HRM, CRM, Projects) before they'll book a demo.
**What I built (independently, end to end):**
- **Module-aware RAG** with Gemini, Gemini Embeddings, Pinecone and PostgreSQL, giving cited answers
- **Multilingual advisor** that detects language and style (English, Sinhala, Tamil, Singlish, Tanglish) and replies in kind
- **Dual-mode UI:** a dedicated advisor workspace plus an embedded website widget with contextual demo-booking lead capture
- **Knowledge pipeline:** ingestion, site crawling, differential vector updates and PostgreSQL ↔ Pinecone sync verification

`Python` `FastAPI` `Gemini` `Pinecone` `PostgreSQL` `Next.js`
